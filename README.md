# Apertra Workspace (customer app)

**Open every market.**

The signed-in Apertra workspace for businesses: shipments, buy requests and escrow, products and classification, documents, the trade network, payments, analytics and settings. Static demo build (front-end only, sample data in the browser).

- Live: https://apertra-trade.github.io/development/workspace.html
- Marketing site: https://apertra-trade.github.io/marketing-landing-Page/ (repo: Apertra-Trade/marketing-landing-Page)
- Employee admin: repo Apertra-Trade/employee-admin-panel
